📋 How to connect your Google Sheet

  1. Sheet has 5 tabs: sales, sales_return, purchases, purchase_return, stock
  2. For sales, sales_return, purchases, purchase_return — just append each month's rows below the previous month. No changes needed.
  3. For stock — before pasting each month's block, add a marker row in column A: MONTH: April 2026, then paste that month's stock report below it. Repeat for each month.
  4. Share sheet as Anyone with link → Viewer
