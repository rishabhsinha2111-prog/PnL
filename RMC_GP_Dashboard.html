How to connect your Google Sheet

  1. Sheet needs 5 tabs: sales, sales_return, purchases, purchase_return, stock
  2. Paste each month's ERP export below the previous one in each tab (keep headers from each export)
  3. For the stock tab — paste months in order Jan→Feb→Mar etc. Each month starts with its own header row
  4. Share as Anyone with link → Viewer, paste URL above and click Load Sheet
